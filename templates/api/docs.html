🚀 ShiftDocs Developer API

API Reference

Integrate high-speed, enterprise-grade file conversions directly into your app. This REST API supports file size limits up to 50MB and runs asynchronously to preserve server responsiveness.

⚡
Base URL
https://shiftdocs.io
🔑
Plan Tier Required
Developer Plan · 5,000 req/mo

1. Authentication

All HTTP requests to the API endpoints must include your unique API key in the Authorization header as a Bearer token.

HTTP Header Example 
Authorization: Bearer YOUR_API_KEY
💡 Need a Key? You can generate, rotate, and copy your live key inside your API & Billing Dashboard.

2. Code Quickstarts

Choose your language below to see how to upload files, handle async tasks, and download output formats.

cURL script 
curl -X POST https://shiftdocs.io/api/v1/convert/pdf_to_images/ \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/doc.pdf"
python requests script 
import requests

url = "https://shiftdocs.io/api/v1/convert/pdf_to_images/"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
files = {"file": open("doc.pdf", "rb")}

response = requests.post(url, headers=headers, files=files)
print(response.json())
axios client script 
const axios = require("axios");
const FormData = require("form-data");
const fs = require("fs");

const form = new FormData();
form.append("file", fs.createReadStream("doc.pdf"));

axios.post("https://shiftdocs.io/api/v1/convert/pdf_to_images/", form, {
  headers: {
    ...form.getHeaders(),
    "Authorization": "Bearer YOUR_API_KEY"
  }
}).then(res => console.log(res.data));

3. Convert Document

Uploads and dispatches a file conversion task asynchronously.

POST /api/v1/convert/{tool_slug}/

API Parameters

Parameter Location Type Required Description
{tool_slug} URL Path string Yes The slug identifier of the conversion tool (e.g. merge_pdf, docx_to_pdf). See list below.
file form-data binary Yes The raw file payload to convert. Maximum size allowed: 50MB.

Response Payload (202 Accepted)

When the request is accepted, the server immediately returns a `202 Accepted` status with job details.

JSON Response 
{
  "status": "processing",
  "job_id": "b78b87ee-c40d-45db-9ce3-1996ec091393",
  "status_url": "https://shiftdocs.io/job/b78b87ee-c40d-45db-9ce3-1996ec091393/status/json/",
  "message": "File queued successfully. Poll the status_url or wait for your webhook."
}

4. Check Job Status

Retrieves the status, conversion progress, error logs, or download link for a processed job.

GET /job/{job_id}/status/json/

Response Payload (200 OK)

5. Sign PDF (Digital Signature)

Digitally signs a PDF document using Level 2 cryptographically secure signatures. Returns the signed PDF file directly.

POST /api/v1/digital-sign/sign/

API Parameters

Parameter Location Type Required Description
file form-data binary Yes The raw PDF file payload to sign. Max size: 50MB.
reason form-data string No The reason for signing. Defaults to Document Signing.
visual_signature form-data string No Whether to draw a visual stamp block ("true" or "false"). Defaults to "true".
position form-data string No Stamp position: bottom_right, bottom_left, top_right, top_left, or center. Defaults to bottom_right.
stamp_style form-data string No Visual card theme: card, minimal, or badge. Defaults to card.
page_choice form-data string No Page to stamp: first or last. Defaults to last.
offset form-data integer No Offset margin in pixels from the page edge. Defaults to 10.

cURL Example

curl -X POST https://shiftdocs.io/api/v1/digital-sign/sign/ \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/doc.pdf" \
  -F "reason=Contract Sign" \
  -F "visual_signature=true" \
  --output signed_doc.pdf

6. Verify Signatures

Verifies the integrity of all digital signatures embedded in a PDF document. Returns verification logs.

POST /api/v1/digital-sign/verify/

API Parameters

Parameter Location Type Required Description
file form-data binary Yes The raw signed PDF file to verify. Max size: 50MB.

Response Payload (200 OK)

{
  "has_signatures": true,
  "status": "valid",
  "summary": "Document is signed and authentic. No modifications detected.",
  "signatures": [
    {
      "signer_name": "John Doe",
      "reason": "Contract Acceptance",
      "signing_time": "2026-06-10 09:12:00 UTC",
      "integrity": "valid"
    }
  ]
}

7. Webhooks (Callbacks)

Instead of polling the status endpoint, you can configure a Webhook URL in your dashboard. When the conversion finishes, our server will automatically send an HTTP POST request directly to your listener.

Webhook POST Payload

JSON Post Received 
{
  "job_id": "b78b87ee-c40d-45db-9ce3-1996ec091393",
  "status": "done",
  "download_url": "https://shiftdocs.io/job/b78b87ee-c40d-45db-9ce3-1996ec091393/download/",
  "error": null
}
