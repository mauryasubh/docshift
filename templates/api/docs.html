ShiftDocs API Reference

Integrate powerful document conversion directly into your application using our REST API.

1. Authentication

Authenticate your requests by sending your API Key in the Authorization header as a Bearer token. 

Authorization: Bearer YOUR_API_KEY

Get your API key →

2. Convert Documents

Submit files for conversion using a multipart/form-data POST request.

POST /api/v1/convert/{tool_slug}/

Parameters

  • tool_slug (url): The tool you wish to run (e.g., merge_pdf, word_to_pdf)
  • file (form-data): The file to convert. Max size: 50MB.

Example Request (cURL)

curl -X POST https://yourdomain.com/api/v1/convert/pdf_to_images/ \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/document.pdf"

3. Webhooks (Callbacks)

Because document conversion can take time, the API returns a 202 Accepted status immediately. Configure a Webhook URL in your dashboard to have ShiftDocs automatically POST the results to your server when finished.

Webhook Payload

{
  "job_id": "b32a9e22-8df3-4c55-b44c-1b77c8e9",
  "status": "done",
  "download_url": "/job/b32a9.../download/",
  "error": null
}
